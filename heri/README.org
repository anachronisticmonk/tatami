#+TITLE: heri — 縁, the border

What ~omote~ and ~toko~ agree on. Nothing else belongs here.

* Contents

- *Schema* — the relational schema Phase 1 infers. Tables, columns, types drawn
  from the lattice of §A2, nullability per column, materialized foreign keys.
  The front end produces it; the back end plans against it.
- *Module surface* — a description of the generated modules: which accessor
  corresponds to which join, which field to which column. Phase 3 needs the
  correspondence, not the emitted text.
- *Effect signatures* — what Phase 2's rewritten accessors perform. Phase 3's
  central question is whether device placement can be read off these, which
  makes them an interface rather than an implementation detail.
- *Observation report* — the S20 per-path counts, if costing turns out to want
  them as statistics.

* Rule

A change here can break either side, so it wants agreement from both before it
lands. That is the whole reason this directory is separate from the two it sits
between: everything else can be changed unilaterally.

Dune enforces the direction — ~omote~ and ~toko~ both depend on ~heri~, and
~heri~ depends on neither.
