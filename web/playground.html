Observations

    
One block per table, with the counts each column's type was derived from. Counts are per visit — once per document for the root table, once per parent for a nested one, once per element for an array — and they keep the difference between an explicit null and an absent member, which option cannot carry.

    

  


  

    The reference implementation is the Lean generator, which compiles to a binary; this page runs it through dev/serve.py when one is reachable, and otherwise falls back to an implementation of the same rules in JavaScript. Objects, nesting and arrays are handled. Arrays of arrays are refused, since the inner table would have no member name to take.
